odelab

GitHub

Interactive tools for ODEs and nonlinear dynamics, backed by a C++ Euler/RK4 core. Type your own equations — every tool accepts arbitrary expressions.

Phase line (ẋ vs x)

1D autonomous systems. Click to drop a particle and watch it flow to a fixed point.

Slope field (t vs x)

Non-autonomous 1D ODEs. Click/drag to place an isocline anywhere on the field.

Direction field (phase plane)

2D systems like Van der Pol and predator-prey. Click to drop a trajectory, drag nullclines.

Lorenz attractor (3D)

The classic chaotic system — same solver, three dimensions.
